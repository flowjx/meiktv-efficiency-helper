# 魅KTV效率助手

Chrome / Edge 浏览器插件：给魅KTV 内部后台加上批量操作和统计功能，少点几百下鼠标。

工具栏图标是**玫红底的白色闪电**。插件只在下面几个页面生效，其他网站完全不受影响。

## 一览：哪个页面、有什么功能

| 页面 | 在哪里找到 | 能做什么 |
|---|---|---|
| **运营后台**<br>`op.meiktv.com`<br>（需要勾选门店的编辑页，如员工、活动、商品等） | 页面右下角红色浮动按钮 **“批量选中门店”** | 粘贴一串门店名，一次性勾选或取消勾选这些门店 |
| **音乐后台 · 播放列表**<br>`music.remote.meiktv.com/music/play.html` | 原“添加”按钮右边的 **“批量添加播放列表”** | 把一个素材一次加到很多门店的播放列表，已有的自动跳过 |
| **音乐后台 · 歌手**<br>`music.remote.meiktv.com/singer/index.html` | “歌手合并”按钮左边的 **“批量添加歌手”** | 一次添加多位歌手，已存在的自动跳过 |
| **禅道 · 测试单列表**<br>`bug.meiktv.com` → 测试 → 测试单 | 表格上方的 **“效率助手”工具栏** | 统计、筛选、搜索测试单，直接看每张单的最新进度，**一键跟进写备注**，导出和复制摘要 |
| **浏览器工具栏** | 点插件图标 | 看当前版本、检查更新、一键重新加载插件 |

> 所有操作都用你**当前登录的账号**执行，插件本身不保存任何账号密码。用之前先在对应后台登录好。

## 1. 运营后台：批量选中门店

**适用场景**：编辑页面上有一大片门店复选框，要从中勾选几十家。

1. 打开需要选门店的编辑页，页面出现“指定门店 / 自定义门店”选项或直营门店列表时，右下角会出现 **“批量选中门店”** 按钮。
2. 点按钮，插件会自动切到“指定门店”模式，并弹出输入框。
3. 按下面的格式粘贴门店名（英文方括号、英文双引号、英文逗号）：

   ```
   ["长沙五一店", "江门万达店", "深圳海岸城店"]
   ```

4. 点 **“选中门店”** 勾选这些门店，或点 **“取消选中”** 取消勾选。下方会显示“已选中 X 家，匹配到 Y 家”。

小贴士：

- 门店名前面的 `A-`、`B-` 这类字母前缀可以不写，插件会自动忽略。
- 直营门店如果按名字匹配不上，也可以直接填门店的数字 ID：`[1, 2, 3]`。
- “匹配到”的数量比你粘贴的少，说明有门店名写得和页面上不一样，检查一下错别字或空格。

## 2. 音乐后台：批量添加播放列表

**适用场景**：一个素材（广告、宣传片等）要加到很多门店的播放列表。

1. 打开音乐后台的播放列表页，点 **“批量添加播放列表”**。
2. **store_id**：粘贴门店 ID，用逗号分隔，例如 `127,128,129`。重复的会自动去掉。
3. **素材 ID**：填**素材页面的 ID，不是歌曲 ID**（最容易填错的地方）。
4. 点 **“预览去重结果”** 确认门店数量，再点 **“开始提交”**。
5. 提交过程中可以看到进度和成功 / 跳过 / 失败的数量：
   - 默认勾选了“先查询，已有素材的门店跳过”，不会重复添加；
   - 可以随时 **暂停 / 继续**；
   - 结束后可以 **重试失败项**，或 **导出成功列表 / 失败列表**（CSV，失败列表带原因）。
6. 如果中途提示“登录已过期”，任务会自动暂停：在后台重新登录后，回来点“继续”即可。

“间隔(ms)”是两次请求之间的等待时间，默认 300 毫秒，一般不用改。

## 3. 音乐后台：批量添加歌手

1. 打开音乐后台的歌手页，点 **“批量添加歌手”**。
2. 每行一位歌手，格式是 `歌手名,简拼,全拼`：

   ```
   蒋菲菲,JFF,JIANGFEIFEI
   周杰伦,ZJL,ZHOUJIELUN
   ```

3. 点 **“预览”** 确认解析结果，再点 **“开始添加”**。
4. 插件分两步执行：先按名字逐个查询，**已存在的歌手自动跳过**；再添加剩下的。结束后显示“已存在 X、新增 Y、失败 Z”。

## 4. 禅道：测试单列表增强

打开禅道「测试 → 测试单」列表，表格上方会多一条 **“效率助手”工具栏**，表格本身也会被加强。

**自动加载全部**：不用翻页，所有测试单一次显示在同一页。

**统计栏（点一下筛选，再点一下取消）**

- **状态**：全部 / 进行中 / 未开始 / 被阻塞 / 已完成，各有多少张。
- **风险**：已逾期、今明到期、3 天无更新、未完成且无备注。
- **负责人**：每人“未完成 / 总数”，比如 `张三 4/6`；鼠标悬停能看到其中逾期几张。

**搜索**

- 搜索框支持 ID、名称、负责人、版本、**备注内容**；多个词用空格分开，表示同时满足（如 `标准店 张三`）。
- 匹配的文字会黄色高亮；在页面上按 `/` 键可以直接跳到搜索框。
- 勾选 **“隐藏已完成”** 只看没做完的。筛选条件会被记住，下次打开还在；点 **“清空筛选”** 恢复。

**表格里多了什么**

- **进度列**：每张测试单最新两条备注（时间精确到分钟，如 `11-13 17:50 张三：冒烟测试通过…`），下面一行是最近一次操作。超过 3 天没有任何记录会标橙色“N 天无更新”。
- **结束日期**：没完成的会标出“逾期 N 天 / 今天到期 / 明天到期”。
- **被阻塞**的行左侧有一条红线；已完成的行变灰。
- **所属产品 / 项目**合并成一列：两个一样只显示一个，不一样时在下面用橙字标出项目名。

**跟进（写备注）**

- 进度列右侧有个玫红色 **“跟进”** 按钮，点开后能看到最近两条备注，写好内容点 **“提交跟进”**（或按 `Ctrl+Enter`）。
- 走的是禅道自带的“编辑测试单”里的备注框：历史记录里会出现一条“你的名字 编辑 + 备注”，测试单的其他内容（负责人、日期、状态等）**原样不变**。
- 提交后插件会重新读取历史记录确认写入成功，进度列马上更新；失败会在弹窗里提示原因（如没有编辑权限、登录过期）。

**按钮**

- **刷新进度**：进度默认缓存 30 分钟，刚加了备注想马上看到就点它。
- **导出CSV**：导出当前筛选出来的测试单（含最新两条备注），可以用 Excel 打开。
- **复制摘要**：把当前筛选结果整理成“被阻塞 / 已逾期 / 今明到期”清单并复制，直接粘贴到企微群即可。

## 5. 工具栏弹窗与更新提醒

点浏览器工具栏上的插件图标（建议先把它**固定到工具栏**）：

- 显示当前版本和最新版本；点 **“立即检查”** 马上检查更新。
- 有新版本时，图标上会出现红色 **“新”** 字，业务页面左下角也会弹一次提示（点“知道了”后，这个版本不再弹）。

**怎么更新**：

1. 用 git 安装的：在插件目录执行 `git pull`；下载安装的：重新下载压缩包，解压后**覆盖**原来的文件夹（位置不要变）。
2. 点插件图标，在弹窗里点 **“我已替换文件，重新加载插件”**，再刷新业务页面。

## 安装

推荐用 git 安装，以后更新只要 `git pull`：

```bash
git clone https://github.com/flowjx/meiktv-efficiency-helper.git
```

不用 git 的话，下载 <https://github.com/flowjx/meiktv-efficiency-helper/archive/refs/heads/main.zip> 并解压。

1. 打开 Chrome/Edge 的扩展程序页面（地址栏输入 `chrome://extensions` 或 `edge://extensions`）。
2. 打开右上角（Edge 在左下角）的 **“开发者模式”**。
3. 点 **“加载已解压的扩展程序”**，选择刚才克隆或解压出来的文件夹（里面直接有 `manifest.json` 的那一层）。
4. 把插件图标固定到工具栏，方便看到更新提醒。

## 常见问题

- **按钮没出现**：确认网址对得上上面的表格；刷新一下页面；在扩展程序页面确认插件是开启状态、没有报错。
- **提示“登录已过期”**：在对应后台重新登录，再点“继续”或重新提交。
- **禅道进度显示“加载失败”**：通常是禅道登录过期，重新登录后点“刷新进度”。
- **更新后没变化**：替换文件后必须“重新加载插件”并刷新页面，两步都要做。

## 隐私说明（安装统计）

为了解大家是否在用、是否已更新，插件每小时最多一次向公司内网统计服务上报：随机生成的安装 ID、插件版本、浏览器和系统，以及在已登录禅道页面看到的**真实姓名、所属部门、职位**。**不采集**禅道用户名（手机号）、邮箱、密码、业务数据。不在公司网络时上报失败会被忽略，不影响使用。

## 维护者说明

更详细的代码结构、接口约定、已知问题见 `HANDOFF.md`。

### 发布新版本

```bash
python scripts/bump_version.py 2.3.4 "更新说明1" "更新说明2"
git add -A
git commit -m "release 2.3.4"
git push
```

脚本会同时修改 `manifest.json` 和 `version.json` 的版本号。推送后，已安装的插件最多 1 小时内会提示更新。只改代码不升版本号，大家不会收到提醒。

### 安装统计服务

`server/install_server.py`（Python 标准库 + `pymysql`），数据写入 MySQL 表 `helper_install`（首次启动自动建表）。

1. 复制 `server/config.example.json` 为 `server/config.local.json`，填写 MySQL 连接（该文件已在 .gitignore 中，**不要提交**）。
2. 双击 `server/启动上报服务.bat` 或执行 `python server/install_server.py`，默认监听 `0.0.0.0:8790`；首次启动会生成查看口令 `admin_key` 写回配置文件。
3. 浏览器打开 `http://<服务器IP>:8790/installs?key=<admin_key>` 查看安装明细。
4. 同事电脑要能访问这台机器的 8790 端口（Windows 防火墙需放行入站）。
5. 开机自启：在“启动”文件夹（`shell:startup`）放一个 vbs，隐藏窗口执行 `python install_server.py >> server.log 2>&1`（vbs 含中文路径时要存成 UTF-16 编码）。

### 重新生成图标

改 `scripts/make_icon.py` 里的颜色或形状，然后执行 `python scripts/make_icon.py`。

### 调试

在目标页面按 F12 打开 Console：运营后台和音乐后台搜 `[门店批量选择助手]`，禅道搜 `[禅道测试单助手]`。运营后台的内容在 iframe 里，Console 左上角要切到对应 frame 才看得到日志。
